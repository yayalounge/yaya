# yaya
- `index.html`, `gerant/` : apps YÄYA Service et Gérant (coques de l'appli Google).
- `apps-script/` : code de l'appli Google (`Code.origine.gs` = sa version actuelle, `Code.gs` = branchée pour la commande à table).
- `commande/` : commande à table par QR code (voir [commande/README.md](commande/README.md)).
